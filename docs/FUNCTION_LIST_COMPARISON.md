# zen-Babel function list comparison: iOS vs HarmonyOS

- **Source:** zen-Babel for iOS 0.9.0 (upstream tag `v0.9.0` plus two commits, `de5465c`), 76 functions.
  The iOS list covers the iPhone app, its share extension and the shared code; the macOS-only features are left out.
- **Target:** zen-Babel for HarmonyOS (`etspworks/ZenBabel-HarmonyOS` dev `80603d0`), 42 functions.
- Both function lists were extracted from each app's source code.
- ✅ = the function is in that app's function list, ❌ = it is not.
- The function text comes from the iOS list, or from the HarmonyOS list when iOS lacks it.
- 81 rows: 62 in both, 14 iOS only, 5 HarmonyOS only.
- A note with #N points to the row whose function gives the same result.
- Level 1 Module is a screen of the app, or Global for launch and app-wide behaviour; Level 2 Module,
  Level 3 Module and Level 4 Module are the elements tapped from it, one level per tap. A row ends at its
  own level, so the deeper columns stay empty. An element that opens further elements (a picker, sheet,
  menu or alert) has its own row first, with its name repeated in the next column. A control of an alert
  that no listed tap opens carries that alert's name in brackets.
- The Target Language Menu and the Developer Panels are Level 1 Modules of their own; the button that
  opens the menu stays in Translation. Share Card is the iOS share extension and the HarmonyOS share card.
- A module, element or page is one merged cell over all the rows of its group. A markdown table cannot
  merge cells, so the table below is written in HTML.
- The same tables are in the workbook [FUNCTION_LIST_COMPARISON.xlsx](FUNCTION_LIST_COMPARISON.xlsx),
  with each group as merged cells.
